## Purpose
The purpose of this repository is to implement testing automation using Cypress for a contact management application. The tests cover basic CRUD operations (Create, Read, Update, Delete) for contacts.

## Technologies Used
- Cypress 12.6.0
- Node.js
- JavaScript
- React (tested application)

## Features
- Automated end-to-end testing
- Contact creation verification
- Contact editing validation
- Contact deletion confirmation
- Real-time feedback on test execution
